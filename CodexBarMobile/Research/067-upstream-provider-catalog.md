# Eight-provider catalog integration

Status: implementation complete; hosted verification pending.

QuotaKit integrates upstream provider catalog additions from `fca039015` and `81438267f`: Tavily, Linkup, TinyApi, Exa, Cosmic AI, Aerostack, Sail Research, and Sofya. The original 92 Mac provider identifiers and order remain unchanged; the eight new IDs are appended at positions 93–100. Provider settings, CLI selection, implementation descriptors, generated aliases, manifests, icon resources, and catalog checks include all eight.

All eight providers report balance or spend data and are not eligible for local model cost estimates or Tier-A account grouping. Linkup, TinyApi, Sail Research, and Sofya are balance-only. Tavily, Exa, Cosmic AI, and Aerostack expose their upstream provider usage; only Tavily, Cosmic AI, and Aerostack carry finite quota windows into shared sync. They are appended to the existing CloudKit notification catalog, increasing its 73-provider set to 76 without changing existing IDs, ordering, record identifiers, or schemas. Linkup, TinyApi, Exa, Sail Research, and Sofya do not receive quota subscriptions. All eight providers send bounded, allowlisted billing details through the existing `SyncProviderDetailSection` payload so successful detail-only balances remain visible on iPhone; account metadata, credentials, actions and unrelated plugin rows remain on Mac. Ollama wallet and JetBrains top-up balances use this same boundary. Successful missing details clear stale rows.

The mobile catalog adds canonical provider identities and branded vector assets for all eight. Provider colors mirror the Mac descriptors except TinyApi and Aerostack, whose upstream swatches collide with existing QuotaKit brands; their colors use the nearest distinct QuotaKit palette values to preserve the mobile brand-separation contract. No persistent configuration, sync payload, CloudKit, App Group, or widget snapshot migration is introduced.

Regression coverage updates the provider architecture gates, account-identity fallback, non-estimated usage cases, quota subscription counts, append-only ordering, palette, brand assets, provider settings, and plugin provider specification catalog. Mobile release notes describe the three synced quota providers. CI must verify the affected Mac and iOS behavior on the final reviewed head; no local Swift build or test suite was run for this source integration.
