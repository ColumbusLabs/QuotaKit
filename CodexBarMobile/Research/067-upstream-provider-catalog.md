# Eight-provider catalog integration

Status: done. Provider catalog parity, mobile billing ingestion, quota subscriptions, palette and assets were verified by hosted lint and iOS checks in [CI run 37923706452](https://github.com/ColumbusLabs/QuotaKit/actions/runs/37923706452) at `bb3ab0afd5b6075f0b526170c36aed8c848c2974`. The later Mac palette correction is documented below; the complete integration still requires all checks on the final reviewed PR head before merge.

QuotaKit integrates upstream provider catalog additions from `fca039015` and `81438267f`: Tavily, Linkup, TinyApi, Exa, Cosmic AI, Aerostack, Sail Research, and Sofya. The original 92 Mac provider identifiers and order remain unchanged; the eight new IDs are appended at positions 93–100. Provider settings, CLI selection, implementation descriptors, generated aliases, manifests, icon resources, and catalog checks include all eight.

All eight providers report balance or spend data and are not eligible for local model cost estimates or Tier-A account grouping. Linkup, TinyApi, Sail Research, and Sofya are balance-only. Tavily, Exa, Cosmic AI, and Aerostack expose their upstream provider usage; only Tavily, Cosmic AI, and Aerostack carry finite quota windows into shared sync. They are appended to the existing CloudKit notification catalog, increasing its 73-provider set to 76 without changing existing IDs, ordering, record identifiers, or schemas. Linkup, TinyApi, Exa, Sail Research, and Sofya do not receive quota subscriptions. All eight providers send bounded, allowlisted billing details through the existing `SyncProviderDetailSection` payload so successful detail-only balances remain visible on iPhone; account metadata, credentials, actions and unrelated plugin rows remain on Mac. Ollama wallet and JetBrains top-up balances use this same boundary. Successful missing details clear stale rows.

The mobile catalog adds canonical provider identities and branded vector assets for all eight. Provider colors mirror the Mac descriptors except TinyApi and Linkup, whose mobile swatches are adapted to avoid existing QuotaKit brands in light or dark appearance. Aerostack uses `#7B6CDB` on both Mac and iPhone: its upstream indigo collided with OpenRouter, and the first adaptation collided with Langdock under the existing Mac separation threshold. The final violet retains its brand family and preserves the unchanged separation gates. No persistent configuration, sync payload, CloudKit, App Group, or widget snapshot migration is introduced.

Regression coverage updates the provider architecture gates, account-identity fallback, non-estimated usage cases, quota subscription counts, append-only ordering, palette, brand assets, provider settings, and plugin provider specification catalog. Mobile release notes describe the three synced quota providers. The hosted iOS run passed 644 Swift Testing cases plus XCTest/UI coverage, including all eleven detail-only billing provider fixtures. Hosted lint confirmed 100 Mac descriptors match the mobile palette and all generated contracts. The complete final-head Mac, iOS, Linux and aggregate qualification is recorded on [PR #235](https://github.com/ColumbusLabs/QuotaKit/pull/235); earlier checks are evidence for this research status, not permission to merge a changed head. No local Swift build or test suite was run for this source integration.
